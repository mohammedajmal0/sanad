# Learning log

One file per phase, named `phase-<N>-<topic>.md`. By week 8 this folder holds every concept learned, every mistake fixed and about 50 interview questions in your own words. It's the interview prep.

## Phase file layout

Each phase file starts with its goal, the "Read first" links from [reading-list.md](../reading-list.md) and the plan's interview questions for that phase. Entries follow below them, newest last.

## Entry format

Append one entry after each task (Claude Code does this, as set in [CLAUDE.md](../../CLAUDE.md)):

```markdown
### YYYY-MM-DD: <task>

**What we built:** one or two lines, with file links.

**Key concepts:**
- concept: one-line explanation in your own words

**Mistakes:**
- what went wrong, why, and what fixed it

**Interview questions:**
1. question only, no answer
2. question only, no answer
3. question only, no answer
```

`/explain-back` and `/interview-drill` also append the gaps they find here.
